Useful Linux Commands

ip addr

Display network interfaces and IP address information.

ip neighbor

Display neighboring network devices.

ps

Display running processes.

top

Monitor running processes and system resources.

nmap

Discover hosts and services on a network.

traceroute

Trace the path packets take through a network.
