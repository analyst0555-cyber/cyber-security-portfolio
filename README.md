## 🔐 Cybersecurity Tools

The website includes interactive cybersecurity learning tools built with HTML, CSS and JavaScript.

### Password Strength Checker

Evaluates password characteristics such as:

- Length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

### IP / Subnet Calculator

Calculates:

- Network Address
- Broadcast Address

### Port Information Checker

Allows users to enter any port number from:

`0 - 65535`

The tool provides information for common ports and services.

Examples include:

| Port | Service |
|---:|---|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |
| 3306 | MySQL |
| 3389 | RDP |
| 5432 | PostgreSQL |
| 27017 | MongoDB |

### Common Port Database

Includes a searchable reference of commonly used network ports and services.
